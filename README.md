# Python Programming Assignment

This repository contains solutions to several Python programming tasks. Each project is implemented in a separate file and demonstrates fundamental programming concepts like loops, functions, and conditional logic.

## Included Projects:
1. **Rock Paper Scissors Game**: A terminal-based game against the computer.
2. **Caesar Cipher**: A tool for encrypting and decrypting text messages.
3. **Simple Calculator**: Performs basic arithmetic with error handling for division by zero.
4. **Number Guessing Game**: A game where the user guesses a random number between 1 and 100.
5. **Student Grade System**: A GPA calculator that converts scores to grades and calculates the final GPA.

## How to Run
Ensure you have Python 3 installed, then run any file using:
`python3 <filename>.py`
